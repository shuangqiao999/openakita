# 知识库检索指南

## 检索步骤

1. **提取关键词**：从用户问题中提取 1-3 个核心词（专有名词优先）。
2. **调用工具**：`search_knowledge_base(query="核心词", top_k=5)`
3. **分析结果**：
   - 结果相关 → 总结引用
   - 结果为空 → 换更宽泛的词重试一次（去修饰词）
   - 仍为空 → 告知用户"知识库中未找到，可以上传相关文档"

## 示例

用户：鲁智深的结局是什么？

步骤：
1. 提取关键词：鲁智深 结局
2. 调用：search_knowledge_base(query="鲁智深 结局")
3. 返回片段：鲁智深坐化六和寺
4. 回答：根据知识库，鲁智深在杭州六和寺圆寂。

用户：Q4 营收是多少？

步骤：
1. 提取关键词：Q4 营收
2. 调用：search_knowledge_base(query="Q4 营收")
3. 空结果 → 换宽泛词：search_knowledge_base(query="营收")
4. 返回片段：...Q4 营收 1200 万...
5. 回答：根据《XX 报告》，Q4 营收为 1200 万。

## 注意事项

- 不要凭记忆回答文档类问题，始终先查知识库
- 一次只搜一个查询，等待结果后再决定下一步
- 内部知识（常识、通用定义）不需要查知识库
