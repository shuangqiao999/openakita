# 长期记忆检索指南

## 检索步骤

1. **提取主题词**：从用户问题中提取相关主题。
2. **调用工具**：`search_memory(query="主题词")`
3. **分析结果**：
   - 相关度高 → 自然地融入回答，不要标注"根据记忆"
   - 相关度低 → 换同义词或更短的关键词重试一次
   - 无结果 → 告知用户"没有找到相关记录"

## 示例

用户：我之前说喜欢的 Python 库是什么？

1. 主题词：喜欢 Python 库
2. 调用：search_memory(query="喜欢 Python 库")
3. 返回：用户喜欢使用 requests 库处理 HTTP 请求
4. 回答：你之前提到喜欢使用 requests 库。

用户：上次我们讨论的那个项目进度怎么样了？

1. 主题词：项目进度
2. 调用：search_memory(query="项目进度")
3. 返回空 → 更短关键词：search_memory(query="项目")
4. 返回：XX 项目正在后台开发阶段
5. 回答：根据之前的记录，XX 项目目前正在后台开发阶段。

## 注意事项

- 对话开头提到"上次"、"之前说过"、"还记得" → 优先查记忆
- 不要凭空编造用户偏好
- 记忆结果与当前对话冲突时，优先使用当前对话的信息
